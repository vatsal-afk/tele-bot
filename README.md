## Setup

```bash
# Install dependencies
npm install

# Copy environment file
cp .env.example .env

# Add your tokens
# TELEGRAM_BOT_TOKEN=your_bot_token
# GROQ_API_KEY=your_groq_api_key

# Run in development
npm run dev

# Or build and run
npm run build
npm start
```

## Commands

- `/start` - Start the bot
- `/dashboard` - View today's status
- `/log` - Log meal/exercise/water
- `/budget` - View budget
- `/weekly` - Weekly summary
